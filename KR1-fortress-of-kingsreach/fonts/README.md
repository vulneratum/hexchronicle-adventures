# Fonts

Fraunces and Libre Baskerville, Latin subsets converted to TrueType from the Fontsource packages. Both are licensed under the SIL Open Font License 1.1, which allows bundling and redistribution: https://openfontlicense.org

Install these on your computer before opening the IDML in DesignCraft or InDesign, or the text will reflow with substitute fonts.
